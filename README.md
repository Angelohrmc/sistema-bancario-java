# Sistema Bancário em Java

## Sobre o projeto

Este projeto foi desenvolvido para praticar os conceitos de Programação Orientada a Objetos (POO) utilizando Java.

## Funcionalidades

- Cadastro e representação de bancos, clientes e contas.
- Consulta de saldo.
- Depósitos e saques.
- Transferências entre contas.
- Validação de operações bancárias.

## Tecnologias utilizadas

- Java
- ArrayList
- LocalDate
- Programação Orientada a Objetos

## Objetivo

Aplicar na prática conceitos de POO, encapsulamento, relacionamento entre classes e implementação de regras de negócio.

## Status

Projeto acadêmico em desenvolvimento.
